# Google Sheets Schema

Create one spreadsheet with the following tabs and columns.

## 1) Daily_Score

| Column | Description |
| --- | --- |
| Date | YYYY-MM-DD |
| Top3 Done | 0-3 |
| Outreach Sent | Integer |
| Income Actions | Integer |
| Credit Action | yes/no or short note |
| Score | 0-10 |
| Notes | What helped or blocked you |

## 2) Leads

| Column | Description |
| --- | --- |
| Date Added | YYYY-MM-DD |
| Source | Upwork, LinkedIn, local business list, etc. |
| Contact Name | Person name |
| Contact Method | Email, DM, form URL |
| Offer | Your service |
| Score | Priority score |
| Status | New, Contacted, Replied, Closed, Lost |
| Next Follow-up | YYYY-MM-DD |
| Notes | Context for personalization |

## 3) Cashflow

| Column | Description |
| --- | --- |
| Date | YYYY-MM-DD |
| Type | Income or Expense |
| Category | Sales, Food, Rent, Ads, etc. |
| Amount | Numeric |
| Description | Short note |

## 4) Credit_Tracker

| Column | Description |
| --- | --- |
| Account | Card or loan name |
| Limit | Credit limit |
| Balance | Current balance |
| Utilization % | (Balance / Limit) * 100 |
| Due Date | YYYY-MM-DD |
| Autopay Enabled | yes/no |
| Last Payment Date | YYYY-MM-DD |
| Notes | Dispute or account notes |

## 5) Wins

| Column | Description |
| --- | --- |
| Date | YYYY-MM-DD |
| Win | What happened |
| Proof | Link, screenshot, or receipt |
| Next Step | Follow-on action |
